Утечка секретов через .claude/settings.local.json: на GitHub найдено 104 185 копий файла

Исследователи Apiiro обнаружили на GitHub 104 185 копий файла .claude/settings.local.json в 103 617 публичных репозиториях. В 1122 изученных файлах содержался как минимум один секрет, а всего исследователи насчитали 1379 уникальных секретов.

Что нашли исследователи

Среди обнаруженных секретов: 398 токенов API, 379 паролей от баз данных, 43 набора учётных данных для подключения по SSH к публичным серверам, 42 токена GitHub, GitLab и npm и 23 ключа AWS.

Причина утечки

Проблема связана с тем, как ИИ-ассистент запоминает разрешения для запуска шелл-команд. Если пользователь выбирает опцию «Yes, and don’t ask again», Claude может сохранить одобренную команду целиком — вместе с токеном, паролем или другими секретами. Такой файл затем может попасть в публичный репозиторий.

Что это означает для разработчиков

Локальные настройки ИИ-ассистентов нужно рассматривать как потенциальный источник секретов. Файлы вроде .claude/settings.local.json не должны попадать в Git, а уже опубликованные секреты следует считать скомпрометированными.

Практические действия

  • Проверить публичные репозитории на наличие .claude/settings.local.json и других локальных файлов настроек.
  • Добавить .claude/settings.local.json в .gitignore и проверить историю Git на уже закоммиченные секреты.
  • Ротировать токены, пароли, SSH-ключи и ключи AWS, если они могли попасть в репозиторий.
  • Не использовать опцию «Yes, and don’t ask again» для команд, содержащих секреты; применять переменные окружения и менеджеры секретов.
  • Настроить сканирование секретов в CI и pre-commit-хуках.

Ограничения и вопросы, требующие проверки

  • Исследование описывает выборку файлов; масштаб реального воздействия может отличаться.
  • Нужно проверить, какие версии Claude и какие конфигурации подвержены проблеме.
  • Следует уточнить рекомендации Apiiro и Anthropic по очистке истории Git и ротации секретов.

Первоисточник: Apiiro — Coding Agents Leaking Secrets on GitHub.
