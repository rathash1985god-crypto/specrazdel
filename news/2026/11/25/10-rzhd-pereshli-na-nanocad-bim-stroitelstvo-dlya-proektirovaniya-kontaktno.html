РЖД перешли на nanoCAD BIM Строительство для проектирования контактной сети

АО «Росжелдорпроекта» утвердило корпоративный стандарт, заменив зарубежные решения отечественным ПО nanoCAD BIM Строительство. Переход затронул проекты электрификации перегона Тейсин – Эльбан и моста через Каму, где внедрены параметрические библиотеки объектов.

Что изменилось в корпоративном стандарте

Руководство холдинга инициировало переход на российское программное обеспечение еще в 2023 году. Ранее автоматизация процессов велась с 2017 года, но базировалась исключительно на зарубежных системах. Теперь ключевые задачи по проектированию контактной сети решаются внутри платформы nanoCAD BIM Строительство.

Разработаны специализированные параметрические библиотеки объектов, включающие опоры и пролеты подвески. В ходе тестирования было загружено 500 сборок опор из этих библиотек. Это позволяет создавать проекты электрификации перегона Тейсин – Эльбан без привязки к иностранному софту.

  • Замена зарубежных решений на отечественный продукт nanoCAD BIM Строительство.
  • Создание параметрических библиотек для опор и пролетов подвески.
  • Применение формата DWG для бесшовной миграции данных внутри компании.

Что это означает для заказчика и бизнеса

Для холдинга, объединяющего более 4000 специалистов в 18 филиалах и 7 региональных подразделениях, переход гарантирует импортозамещение критически важного ПО. Это снижает риски задержек строительства из-за ошибок в проекте.

Автоматизация расчетов для линейных объектов уменьшает затраты на переделку документации благодаря раннему выявлению разночтений между разделами проекта. Обе стороны выигрывают от повышения точности проектирования сложных инфраструктурных объектов, таких как мосты и перегоны.

  • Снижение рисков срыва сроков строительства за счет минимизации ошибок.
  • Уменьшение затрат на переделку рабочей документации.
  • Прямое взаимодействие с российским разработчиком для доработки функционала под отраслевые нужды.

Что учесть проектировщику и ГИПу

Инженер получает инструмент для самостоятельной разработки параметрических библиотек без привлечения сторонних разработчиков. Это позволяет сократить время на расчеты и минимизировать ошибки при изменении геометрии опор.

При работе с мостами длиной более 1 км, например через Каму, важно использовать автоматизацию процессов. Игнорирование перехода на параметрическое моделирование влечет за собой рост количества ошибок: изменение положения одной опоры меняет более 13 позиций спецификации.

  • Необходимость освоения новой платформы и настройки автоматизации под конкретные задачи.
  • Использование формата IFC для взаимодействия со смежниками.
  • Контроль корректности пересчета спецификаций при изменении геометрии объектов.

Преимущества внедрения параметрических библиотек

Внедрение позволяет ускорить выпуск рабочей документации за счет автоматического обновления связанных элементов. Проектировщики могут оперативно корректировать схемы, не внося хаос в базу данных.

Нативная поддержка отечественных форматов и возможность расширения функционала через открытый API делают систему гибкой. Это особенно актуально для крупных инфраструктурных проектов с высокой степенью детализации.

  • Повышение производительности труда за счет автоматизации рутинных операций.
  • Возможность создания уникальных библиотек под специфику линейных объектов.
  • Снижение количества человеческих ошибок при масштабировании проекта.

Ограничения и риски перехода

Главный минус заключается в необходимости времени для освоения новой платформы. Командам потребуется время на адаптацию к интерфейсу и логики параметрического моделирования.

Риск существует, если автоматизация не настроена под конкретные задачи компании. Без должной подготовки переход может привести к временным сбоям в работе вместо ожидаемого ускорения процессов.

  • Требуются ресурсы на обучение персонала новым инструментам.
  • Необходимость тщательной настройки автоматизации для каждого типа объекта.
  • Временные затраты на миграцию существующих данных из старых систем.

Практические действия для внедрения

Компания должна начать с создания базовых параметрических библиотек опор и пролетов подвески, аналогично тому, как это было сделано для тестирования 500 сборок.

Необходимо обеспечить совместимость форматов DWG и IFC для бесшовной работы внутри холдинга и взаимодействия со смежниками.

  • Разработать корпоративные стандарты использования параметрических библиотек.
  • Провести обучение специалистов по работе с открытым API платформы.
  • Настроить автоматизацию расчетов для типовых узлов контактной сети.
